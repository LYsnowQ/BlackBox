# BlackBox 整体风格样式指南

> 本文档依据 `entry/src/main/ets/pages/profile/Demo.ets` 收敛后的视觉实现整理，作为 **全 App 统一样式与风格约束**。  
> **仅规范视觉与文案气质，不涉及具体业务功能。**

---

## 1. 设计参照与气质

### 1.1 参照来源
- 布局与信息层级：参考 **软件小黑盒** 个人主页的结构节奏（顶栏 → 封面 → 身份区 → 数据 → 操作 → 分栏 → 内容流）。
- 视觉落地：在参照基础上做 **简约、柔和、克制** 的二次收敛，而非高饱和游戏风堆砌。

### 1.2 整体气质关键词
| 要 | 不要 |
|----|------|
| 安静、留白、纸面/夜色感 | 喧闹、霓虹、信息过载 |
| 单一品牌强调色 | 多色标签竞赛 |
| 轻字重、清晰字阶 | 到处加粗、字号混乱 |
| 靠底色与间距分区 | 厚描边、重阴影、碎装饰 |
| 短句、少符号 | 口号堆砌、emoji 满屏 |

### 1.3 一句话原则
**少一层装饰，多一分呼吸；颜色只服务层级，文字只服务阅读。**

## 2. 主题体系

App 支持 **暗夜 / 日间** 两套主题，结构一致、色值成对映射。新页面必须同时适配两套，禁止只做单主题。

### 2.1 暗夜盒（Dark）— 默认气质

| Token | 色值 | 用途 |
|-------|------|------|
| `pageBg` | `#12141A` | 页面底、顶栏底 |
| `cardBg` | `#1A1D24` | 卡片、内容容器 |
| `textPrimary` | `#E8EAED` | 主标题、关键数字、主按钮文字（非强调底时） |
| `textSecondary` | `rgba(232,234,237,0.58)` | 正文、签名 |
| `textTertiary` | `rgba(232,234,237,0.38)` | 辅助标签、次要说明 |
| `textHint` | `rgba(232,234,237,0.28)` | 时间、页脚、空态提示 |
| `textOnAccent` | `#12141A` | 落在强调色底上的文字 |
| `surface` | `rgba(255,255,255,0.06)` | 弱底（标签、次按钮、图占位） |
| `divider` | `rgba(255,255,255,0.06)` | 分割线 |
| `accent` | `#5ED9A0` | 品牌绿：主按钮、指示条、关键标签字色 |
| `accentSoft` | `rgba(94,217,160,0.12)` | 等级等轻提示底 |
| `coverTop` | `#1C2430` | 封面渐变起点 |
| `coverBottom` | `#12141A` | 封面渐变终点（与 pageBg 衔接） |
| `progressTrack` | `rgba(255,255,255,0.08)` | 进度条轨道 |

### 2.2 日间盒（Light）

| Token | 色值 | 用途 |
|-------|------|------|
| `pageBg` | `#F7F6F3` | 暖纸白页面底 |
| `cardBg` | `#FFFFFF` | 卡片 |
| `textPrimary` | `#2A2C30` | 主文字 |
| `textSecondary` | `rgba(42,44,48,0.58)` | 正文 |
| `textTertiary` | `rgba(42,44,48,0.40)` | 辅助 |
| `textHint` | `rgba(42,44,48,0.30)` | 提示 |
| `textOnAccent` | `#FFFFFF` | 强调色上的文字 |
| `surface` | `rgba(42,44,48,0.05)` | 弱底 |
| `divider` | `rgba(42,44,48,0.07)` | 分割线 |
| `accent` | `#3CB87A` | 品牌绿（略沉，保证纸面可读） |
| `accentSoft` | `rgba(60,184,122,0.10)` | 轻提示底 |
| `coverTop` | `#E4EFE8` | 封面浅绿雾 |
| `coverBottom` | `#F7F6F3` | 衔接到页面底 |
| `progressTrack` | `rgba(42,44,48,0.08)` | 进度条轨道 |

### 2.3 主题约束
1. **禁止** 在业务页硬编码与 Token 无关的新主色。
2. **强调色只有一个家族**（品牌绿）；状态色（成功/警告/错误）若未来需要，须单独定义且克制使用，不得替代品牌主色做装饰。
3. 封面、头像描边等过渡色必须 **回到 `pageBg`**，避免断层色块。
4. 暗色文字透明度以 **Primary / 0.58 / 0.38 / 0.28** 四档为基准；亮色同理。勿随意新增透明度档位。

## 3. 字体与字阶

### 3.1 字阶表（全 App 统一）

| 层级 | 字号 | 字重 | 行高建议 | 字距 | 典型场景 |
|------|------|------|----------|------|----------|
| 页面大标题 | 20 | Medium | — | 0.3 | 昵称、一级标题 |
| 导航标题 | 16 | Medium | — | 0.5 | 顶栏居中标题 |
| 卡片标题 | 15 | Medium | 22 | 0.2 | 列表/动态标题 |
| 正文 | 13 | Regular / Normal | 20–21 | 0 | 签名、摘要、说明 |
| 辅助 | 12 | Regular | — | 0–0.2 | 次级信息、互动数 |
| 标签 / 提示 | 11 | Medium 或 Regular | — | 0.2–0.3 | 兴趣标签、Tab 辅助、meta |
| 图标化符号 | 26 | Lighter | — | 0 | 返回「‹」等 |

### 3.2 字重原则
- **默认不用 Bold**；重要信息优先用字号与颜色层级，其次用 Medium。
- 返回、弱操作可用 **Lighter**，体现轻量。
- 禁止同一区块内多种字重混战（例如标题 Bold + 副标 Medium + 正文 Medium）。

### 3.3 文案气质（样式相关）
- 短句优先；能一行说完不拆两行装饰。
- 少用书名号堆叠、少用「——」超长破折；间隔符统一用 **` · `**（中点两侧空格）。
- 页脚、空态用平静短句（如「已经到底了」「稍后再来看看」），避免营销口号。
- **默认不使用 emoji** 作为界面符号；若必须，仅限极少数且不参与层级竞争。

## 4. 布局与间距

### 4.1 基准栅格
- 页面水平安全边距：**16–20**（内容区推荐 **20**，卡片外边距可用 **16**）。
- 卡片内边距：**16**。
- 主要区块垂直节奏：约 **12 / 14 / 16 / 18 / 22**，优先偶数，避免 1–3px 碎间距。

### 4.2 结构节奏（推荐页面骨架）
```
状态栏占位
顶栏（高 48）
[可选封面 / 头部视觉]
主体信息区
数据或摘要区
主操作区
分栏（Tab）
内容流 / 列表
底部留白（约 28–36）
```
- 不必每页都有封面，但 **顶栏 + 内容 + 底部呼吸** 应保持。
- 滚动容器默认隐藏滚动条，边缘回弹可保留系统柔和效果。

### 4.3 对齐
- 顶栏：左操作 / 中标题 / 右操作，标题视觉居中。
- 数据横排：等分 `layoutWeight`，**不用竖分割线**，靠对齐与间距区分。
- 列表卡片：左右边距一致，卡片之间间距统一（如 **12**）。

## 5. 形状、表面与层次

### 5.1 圆角
| 元素 | 圆角 |
|------|------|
| 大卡片 / 内容卡 | **14** |
| 中等容器 / 配图占位 | **10** |
| 胶囊按钮 / 圆形热区 | **20** 或高度一半 |
| 小标签 / 等级 | **4–11**（标签偏圆：约 11；等级偏方：约 4） |
| 进度条 | **2**（高度 4） |
| Tab 指示条 | **1**（宽约 16、高 2） |

### 5.2 边框与阴影
- **默认无描边、无投影**。
- 分区优先：`pageBg` vs `cardBg` vs `surface`。
- 分割线仅在 Tab 底等「必须」处使用，颜色用 `divider`，线宽 **0.5**。
- 禁止为「好看」给每张卡加边框或重阴影。

### 5.3 表面层级（由底到顶）
1. `pageBg` — 画布  
2. `cardBg` — 内容承载  
3. `surface` — 弱控件、占位、次按钮  
4. `accent` / `accentSoft` — 强调与轻提示

## 6. 组件样式约定

### 6.1 顶栏
- 高度 **48**；状态栏占位单独约 **36**（按设备可调，但风格保持「干净一条」）。
- 返回：轻字重符号，热区约 **40×40**，无重底或仅必要时用 `surface`。
- 右侧工具：优先 **单字/单图标**，底用 `surface` 圆形，避免多按钮并排拥挤。

### 6.2 按钮
| 类型 | 样式 |
|------|------|
| 主按钮 | 高 **40**，圆角 **20**，底 `accent`，字 `textOnAccent`，字号 14 Medium |
| 次按钮 | 同尺寸，底 `surface`，字 `textPrimary`，**无描边** |
| 已选/弱化主操作 | 底 `surface`，字 `textSecondary` |

- 同一操作区按钮数量宜 **≤ 2**；更多收纳，不在主路径堆砌。

### 6.3 标签
- 字号 11，水平 padding 约 **10**，垂直约 **5**。
- 底 `surface`，字 `textTertiary`；**无边框**。
- 内容标签若需强调，可用 `accent` 字色 + 无底或极轻 `accentSoft`，**禁止彩虹色标签墙**。

### 6.4 Tab
- 字号 **14**；选中 `textPrimary` + Medium，未选中 `textTertiary`。
- 指示条：宽约 **16**、高 **2**、色 `accent`；未选中宽度为 0。
- 底部分割线可选，须极淡。

### 6.5 卡片 / 列表项
- 背景 `cardBg`，圆角 14，内边距 16。
- 标题 → 正文 → 媒体占位 → 元信息，纵向节奏固定。
- 媒体占位优先 **单块** 柔和 `surface`，避免多宫格碎块（除非内容语义必须多图）。
- 互动区用纯文字数字（如 `2.1k 赞`），不强制图标。

### 6.6 进度
- 轨道高 **4**，`progressTrack`；填充 `accent`，无渐变炫光亦可。
- 说明文字用 `textHint` / `textTertiary`，不抢主数字。

### 6.7 空态与页脚
- 居中短文案；主句 13–14 + `textTertiary`，副句 12 + `textHint`。
- 禁止大插画堆砌（除非品牌统一资源且留白充足）。
- 列表底部一句收束即可，如「已经到底了」。

### 6.8 头像与封面
- 头像：圆形，强调色底 + 单字/图；描边与 `pageBg` 同色衔接（约 3px）。
- 封面：低对比渐变，高度克制（约 **140**）；角标可用极淡大写英文（如 `NIGHT` / `DAY`），字号 10、字距约 3。
- **禁止** 多层光晕、粒子、强对比装饰块。

---

## 7. 图标与占位

- 系统/线性图标优先，线宽视觉与字重 Medium 协调。
- 图片未就绪时：使用 `surface` 色块圆角占位，**不写花哨 IMG 水印**（Demo 中可无字）。
- 切图风格：低对比、少描边、与主题明暗成套提供。

---

## 8. 动效与交互反馈（风格向）

- 主题切换：即时换色即可，不必夸张过渡。
- 点击态：轻微透明度或系统默认即可，避免大幅缩放弹跳。
- 滚动：弹簧边缘可保留；忌炫光、视差过强。
- 所有反馈服务于「安静」，不服务于「炫技」。

---

## 9. 强制限制（Do / Don’t）

### 9.1 必须做到
1. 新页面颜色来自主题 Token，明暗双套同步。  
2. 字阶落在第 3 章表格内，不随意发明字号。  
3. 主强调色仅品牌绿家族。  
4. 卡片默认无描边、无重阴影。  
5. 水平边距与卡片间距全 App 一致量级。  
6. 文案短、层级清、装饰少。

### 9.2 明确禁止
1. 高饱和多色标签、霓虹渐变按钮、大面积玻璃拟态滥用。  
2. 同屏多个主按钮争抢。  
3. 为装饰增加无意义分割线、图标、角标。  
4. Bold 字重泛滥或字号阶梯超过指南。  
5. 亮色主题使用暗色专用高亮绿（或反之）导致对比失调。  
6. 在样式层引入与 Demo 气质冲突的「赛博/电竞贴纸」风。

---

## 10. 实现落点建议（非功能）

- 将 `ThemePalette` 与 `darkTheme` / `lightTheme` 抽为 **全局样式模块**，各页只消费 Token。  
- 字号、圆角、间距可沉淀为命名常量（如 `Font.cardTitle = 15`，`Radius.card = 14`）。  
- 资源色若进 `color.json`，命名与 Token 对齐（`page_bg`、`text_primary`、`accent`…），并维护 dark 资源目录。  
- Code Review 视觉项：只问「是否更安静、是否仍只有一个强调色、字阶是否出表」。
